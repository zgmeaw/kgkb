# 公考岗位智能分析系统

一款智能化的公考岗位分析工具，帮助考生快速找到最适合的岗位。

## 功能特性

### 核心功能
- 📢 **公告管理** - 管理和查看各类公考招录公告信息
- 🎯 **岗位分析** - 智能分析岗位要求，计算匹配度
- 👤 **个人档案** - 完善个人信息，获得精准匹配
- 📊 **数据导出** - 导出分析结果，方便查看和分享

### 技术特性
- ⚡️ React 19 + TypeScript - 类型安全的现代化开发
- 🎨 Tailwind CSS - 响应式设计，支持移动端
- 📦 Vite - 快速的开发和构建体验
- 💾 LocalStorage - 本地数据存储，无需后端
- 📥 Excel 导入导出 - 批量处理岗位数据
- 🔍 智能匹配算法 - 多维度岗位匹配分析

## 使用指南

### 1. 创建个人档案
- 进入"个人档案"页面
- 填写学历、专业、工作经验等信息
- 保存档案

### 2. 添加招录公告
- 进入"公告管理"页面
- 点击"创建公告"按钮
- 填写公告信息并保存

### 3. 导入岗位数据
- 进入"岗位列表"页面
- 选择对应的公告
- 点击"导入岗位"按钮
- 上传Excel文件（可先下载模板）

### 4. 查看匹配结果
- 系统自动计算每个岗位的匹配度
- 按匹配度排序显示
- 点击岗位卡片查看详细信息

## Excel 导入格式

岗位数据Excel文件应包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 岗位代码 | 岗位唯一标识 | 001 |
| 岗位名称 | 岗位名称 | 综合管理岗 |
| 招录部门 | 招录单位 | 某某局 |
| 岗位类别 | 岗位分类 | 综合管理类 |
| 招录人数 | 计划招录人数 | 1 |
| 学历要求 | 最低学历要求 | 本科 |
| 学位要求 | 学位要求 | 学士 |
| 专业要求 | 专业限制 | 计算机科学与技术、软件工程 |
| 政治面貌 | 政治面貌要求 | 中共党员、中共预备党员 |
| 工作经验 | 是否需要工作经验 | 否 |
| 最小年龄 | 年龄下限 | 18 |
| 最大年龄 | 年龄上限 | 35 |
| 工作地点 | 工作地点 | 北京市 |
| 岗位职责 | 岗位职责描述 | 负责日常管理工作 |

## 匹配算法说明

系统采用多维度加权匹配算法，各维度权重如下：

- 学历匹配：25%
- 学位匹配：20%
- 专业匹配：25%
- 政治面貌：10%
- 工作经验：15%
- 年龄要求：5%

匹配度等级：
- 90分以上：优秀匹配（绿色）
- 75-89分：良好匹配（蓝色）
- 60-74分：一般匹配（黄色）
- 60分以下：匹配度低（红色）

## 部署

### GitHub Pages

1. 推送代码到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择GitHub Actions作为部署源
4. 推送到main分支会自动触发部署

### Cloudflare Pages

1. 连接GitHub仓库到Cloudflare Pages
2. 设置构建命令：`npm run build`
3. 设置输出目录：`dist`
4. 部署
